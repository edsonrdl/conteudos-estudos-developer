## O que é o Correlation ID?

Imagine que um usuário clica em "Comprar" no seu app. Esse único clique dispara uma reação em cadeia: o serviço de pedidos chama o serviço de estoque, que chama o de pagamento, que por sua vez avisa o envio.

Se o pagamento falhar, como você rastreia esse erro entre quatro servidores diferentes?

O **Correlation ID** é um identificador único (geralmente um UUID/GUID) gerado no início da requisição e passado de serviço em serviço. Ele serve como uma "etiqueta" que agrupa todos os logs de uma mesma transação original.

### Por que usar?

- **Rastreabilidade:** Permite filtrar logs de diferentes máquinas para ver o fluxo completo de uma requisição.
    
- **Debugging:** Identifica exatamente onde a corrente quebrou.
    
- **Monitoramento:** Ajuda a medir a latência total de uma operação complexa.

## Como enviar no Header da Request

Não existe um padrão oficial da HTTP (como o `Content-Type`), mas o mercado convencionou usar nomes específicos. O mais comum é:

- `X-Correlation-ID`
    
- `X-Request-ID`
    

### Exemplos práticos:

#### 1. Usando cURL (Terminal)

Bash

```
curl -H "X-Correlation-ID: 123e4567-e89b-12d3-a456-426614174000" https://api.sua-app.com/v1/pedidos
```

#### 2. Usando JavaScript (Fetch API)

```
const correlationId = crypto.randomUUID(); // Gera um ID único

fetch('https://api.sua-app.com/v1/pedidos', {
    method: 'POST',
    headers: {
        'Content-Type': 'application/json',
        'X-Correlation-ID': correlationId
    },
    body: JSON.stringify({ item: 'Teclado' })
});
```

#### 3. Usando Axios (Node.js/React)


```
axios.get('/user/123', {
    headers: {'X-Correlation-ID': 'meu-id-unico-999'}
});
```

## Boas Práticas

- **Gere na borda:** O primeiro serviço que recebe a request (ou o próprio Frontend) deve gerar o ID se ele não existir.
    
- **Propague:** Sempre pegue o ID recebido e envie-o para as próximas chamadas de API internas.
    
- **Logue tudo:** Garanta que seu sistema de log (como ELK Stack ou Splunk) esteja configurado para exibir esse ID em cada linha de mensagem.
