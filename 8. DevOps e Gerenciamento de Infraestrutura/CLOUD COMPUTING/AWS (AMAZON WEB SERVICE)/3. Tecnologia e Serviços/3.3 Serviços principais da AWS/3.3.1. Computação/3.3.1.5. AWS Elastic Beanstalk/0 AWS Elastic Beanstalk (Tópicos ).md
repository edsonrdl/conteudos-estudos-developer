# 📚 Guia de Estudos: AWS Elastic Beanstalk
#tag #aws #cloud #computacao #beanstalk #paas

> [!info] Visão Geral
> AWS Elastic Beanstalk é o serviço PaaS (Platform as a Service) da AWS: você fornece o código da aplicação, e o Beanstalk provisiona e gerencia automaticamente a infraestrutura necessária — instâncias EC2, load balancer, Auto Scaling, monitoramento e deploys. É a forma mais rápida de colocar uma aplicação web em produção na AWS sem configurar infraestrutura manualmente. Ideal para equipes que querem focar no código sem se preocupar com operações de servidor, e para migrações de aplicações existentes com mínima reescrita.
