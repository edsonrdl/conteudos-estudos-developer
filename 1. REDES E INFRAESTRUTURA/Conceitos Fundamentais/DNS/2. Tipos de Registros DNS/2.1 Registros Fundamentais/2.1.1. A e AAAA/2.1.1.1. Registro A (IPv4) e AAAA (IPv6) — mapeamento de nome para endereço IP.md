### Registros A e AAAA — mapeamento de nome para endereço IP

Os registros A e AAAA são os mais fundamentais do DNS: eles respondem à pergunta "qual é o endereço IP deste domínio?". São a razão pela qual você pode digitar `google.com` em vez de um número.

---

## Registro A — IPv4

Mapeia um nome de domínio para um endereço **IPv4** (32 bits, formato `x.x.x.x`).

```
google.com.    300    IN    A    142.250.79.46
```

| Campo | Valor | Significado |
|---|---|---|
| Nome | `google.com.` | Domínio consultado |
| TTL | `300` | Segundos que o cache é válido |
| Classe | `IN` | Internet (sempre IN) |
| Tipo | `A` | Tipo do registro |
| RDATA | `142.250.79.46` | Endereço IPv4 |

Um domínio pode ter **múltiplos registros A** (round-robin DNS) para distribuir carga entre servidores.

---

## Registro AAAA — IPv6

Mapeia um nome de domínio para um endereço **IPv6** (128 bits, formato hexadecimal).

```
google.com.    300    IN    AAAA    2607:f8b0:4004:c09::71
```

O nome "AAAA" vem do fato de que um endereço IPv6 tem 4× mais bits que um IPv4 (128 vs 32) — quatro vezes a letra A.

---

## Coexistência A e AAAA

Um mesmo domínio pode ter ambos:

```
meusite.com.    IN    A       203.0.113.10
meusite.com.    IN    AAAA    2001:db8::1
```

O cliente escolhe qual usar com base na sua conectividade. Navegadores modernos tentam IPv6 primeiro via **Happy Eyeballs** (RFC 8305).

---

## Casos de uso práticos

- Apontar `www.minhaempresa.com` para o IP do servidor web.
- Múltiplos registros A para balanceamento de carga simples.
- Registro AAAA obrigatório em infraestruturas que suportam IPv6.

---

## 🧩 Quiz de Fixação

1. Qual a diferença entre os registros A e AAAA?
2. O que acontece quando um domínio tem 3 registros A diferentes?
3. Por que o registro AAAA se chama AAAA?

**Respostas:**
1) A aponta para IPv4 (32 bits); AAAA aponta para IPv6 (128 bits).
2) O DNS retorna os três IPs e o cliente (ou resolver) pode usar round-robin para distribuir as conexões.
3) IPv6 tem 128 bits — 4× mais que IPv4 (32 bits), daí quatro letras A.
