### Registro CNAME — alias de um nome para outro nome

O CNAME (Canonical Name) cria um apelido que aponta de um nome de domínio para outro nome de domínio — não para um IP. É como um redirecionamento no nível do DNS.

---

## Como funciona

```
www.meusite.com.    IN    CNAME    meusite.com.
meusite.com.        IN    A        203.0.113.10
```

Quando alguém resolve `www.meusite.com`:
1. DNS retorna: "esse nome é um CNAME para `meusite.com`"
2. DNS resolve `meusite.com` → `203.0.113.10`
3. Conexão vai para `203.0.113.10`

O cliente faz **duas consultas**: primeiro resolve o CNAME, depois resolve o alvo.

---

## Casos de uso comuns

| Cenário | Exemplo |
|---|---|
| Subdomínio `www` aponta para o domínio raiz | `www` → `meusite.com` |
| Serviços externos (CDN, SaaS) | `assets.meusite.com` → `meusite.cloudfront.net` |
| Múltiplos nomes para o mesmo servidor | `api.meusite.com` → `backend.meusite.com` |

---

## Restrições importantes

**1. CNAME não pode coexistir com outros registros no mesmo nome.**
```
# INVÁLIDO — CNAME no apex com MX
meusite.com.    IN    CNAME    outro.com.   ← PROIBIDO no apex
meusite.com.    IN    MX       10 mail...   ← não pode coexistir
```

Por isso, o CNAME **nunca deve ser usado no domínio raiz** (apex). Use registros A/AAAA diretamente no apex, ou o recurso "ALIAS/ANAME" de alguns provedores.

**2. CNAME não pode apontar para um IP**, apenas para outro nome de domínio.

---

## CNAME vs A

| | Registro A | Registro CNAME |
|---|---|---|
| Aponta para | Endereço IP | Outro nome de domínio |
| Uso no apex | Sim | Não |
| Coexiste com outros | Sim | Não |
| Consultas necessárias | 1 | 2+ |

---

## 🧩 Quiz de Fixação

1. O que um registro CNAME armazena como destino?
2. Por que não se deve usar CNAME no domínio raiz (apex)?
3. `loja.meusite.com CNAME meusite.shopify.com` — o que acontece quando alguém acessa `loja.meusite.com`?

**Respostas:**
1) Outro nome de domínio (não um IP).
2) O apex precisa coexistir com registros SOA e NS, o que viola a regra de que CNAME não pode coexistir com outros registros.
3) O DNS resolve `loja.meusite.com` → CNAME → `meusite.shopify.com` → IP do Shopify; o cliente conecta ao servidor Shopify.
