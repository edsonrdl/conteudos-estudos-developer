### O que é DNS e como funciona a resolução de nomes

O DNS (Domain Name System) é o sistema que traduz nomes de domínio legíveis por humanos (como `google.com`) em endereços IP que os computadores usam para se comunicar. Sem ele, seria necessário memorizar sequências numéricas para acessar qualquer site.

---

## O problema que o DNS resolve

Computadores se comunicam usando endereços IP — sequências numéricas como `142.250.79.46`. Humanos trabalham melhor com nomes descritivos como `google.com`. O DNS é a ponte entre esses dois mundos.

```
Usuário digita: google.com
       ↓
    Resolver DNS
       ↓
  Resposta: 142.250.79.46
       ↓
  Navegador conecta ao IP
```

A analogia clássica é a de uma **lista telefônica**: você procura o nome da pessoa e obtém o número. O DNS faz o mesmo — você fornece o nome do domínio e recebe o endereço IP.

---

## Estrutura de um nome de domínio

Um domínio como `www.google.com` é lido da direita para a esquerda na hierarquia DNS:

| Parte | Nome técnico | Exemplo |
|---|---|---|
| `.` (implícito) | Raiz (Root) | `.` |
| `com` | TLD (Top-Level Domain) | `com`, `br`, `org` |
| `google` | Domínio de segundo nível (SLD) | `google` |
| `www` | Subdomínio | `www`, `mail`, `api` |

---

## Por que o DNS é crítico

- **Escalabilidade:** há bilhões de domínios — impossível manter uma lista central.
- **Distribuição:** a responsabilidade é delegada em hierarquias (raiz → TLD → domínio).
- **Cache:** respostas são armazenadas temporariamente para reduzir latência.
- **Resiliência:** múltiplos servidores evitam ponto único de falha.

## 🧩 Quiz de Fixação

1. Qual é a função principal do DNS?
2. Na URL `api.empresa.com.br`, identifique o TLD, o domínio de segundo nível e o subdomínio.
3. Por que é inviável ter um único servidor DNS central para toda a internet?

**Respostas:**
1) Traduzir nomes de domínio em endereços IP (resolução de nomes).
2) TLD: `br` (e `com` é 2nd-level sob `br`); domínio: `empresa`; subdomínio: `api`.
3) Seria um ponto único de falha, não escalaria para bilhões de domínios e criaria gargalo global de latência.
