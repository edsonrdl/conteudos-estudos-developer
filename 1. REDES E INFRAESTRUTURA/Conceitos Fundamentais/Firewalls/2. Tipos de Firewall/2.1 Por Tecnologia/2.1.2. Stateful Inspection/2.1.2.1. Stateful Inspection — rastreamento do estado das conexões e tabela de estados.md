### Stateful Inspection — rastreamento do estado das conexões

O stateful inspection (inspeção com estado) resolve a principal limitação do packet filtering: a memória de conexão. Ele mantém uma tabela de conexões ativas e usa esse contexto para decidir se um pacote pertence a uma sessão legítima.

---

## A tabela de estados (State Table)

Cada conexão TCP estabelecida é registrada:

```
┌──────────────────┬─────────────────┬───────┬──────────┬────────┐
│ IP Origem        │ IP Destino      │ Proto │ Porta    │ Estado │
├──────────────────┼─────────────────┼───────┼──────────┼────────┤
│ 192.168.1.10     │ 142.250.79.46   │ TCP   │ 52341:80 │ ESTAB  │
│ 192.168.1.15     │ 8.8.8.8         │ UDP   │ 54210:53 │ NEW    │
│ 192.168.1.20     │ 104.16.0.0      │ TCP   │ 49200:443│ ESTAB  │
└──────────────────┴─────────────────┴───────┴──────────┴────────┘
```

---

## Estados de uma conexão TCP

```
NEW         → primeiro pacote (SYN) — conexão sendo iniciada
ESTABLISHED → handshake completo — dados fluindo
RELATED     → conexão secundária relacionada (ex: FTP data channel)
INVALID     → pacote que não se encaixa em nenhum estado conhecido
```

---

## Como resolve o problema do tráfego de retorno

```
Stateful:
  Saída: 192.168.1.10:1234 → 8.8.8.8:80  → cria entrada na tabela (ESTABLISHED)
  Retorno: 8.8.8.8:80 → 192.168.1.10:1234 → firewall verifica tabela → pertence a conexão existente → ALLOW automático
```

Não é necessária regra explícita para o tráfego de retorno — o estado da conexão já autoriza.

---

## Vantagens sobre packet filtering

| Aspecto | Packet Filtering | Stateful |
|---|---|---|
| Tráfego de retorno | Regra explícita necessária | Automático via tabela |
| IP Spoofing | Vulnerável | Difícil (valida sequência TCP) |
| SYN Flood | Vulnerável | Detecta anomalias de estado |
| Complexidade de regras | Alta | Menor |

---

## Limitações

- **Sem visibilidade de aplicação (L7):** ainda não enxerga o conteúdo dos pacotes.
- **Tabela de estados consome memória:** ataques de SYN flood podem esgotar a tabela.
- **Não detecta ataques em conexões válidas:** SQL injection em HTTP estabelecido passa.

---

## 🧩 Quiz de Fixação

1. O que é a tabela de estados e para que ela serve?
2. O estado RELATED é usado em qual cenário prático?
3. Um atacante envia pacotes TCP com flag ACK sem SYN prévio (ACK scan). Como o stateful firewall trata isso?

**Respostas:**
1) É uma tabela em memória que registra todas as conexões ativas — permite que o firewall saiba se um pacote de retorno pertence a uma sessão legítima sem precisar de regra explícita.
2) Em protocolos como FTP ativo, onde a conexão de dados é iniciada pelo servidor em uma porta diferente da de controle — o RELATED permite essa conexão secundária automaticamente.
3) O pacote ACK sem entrada correspondente na tabela de estados é classificado como INVALID e descartado — o stateful detecta que não existe SYN prévio para aquela sessão.
