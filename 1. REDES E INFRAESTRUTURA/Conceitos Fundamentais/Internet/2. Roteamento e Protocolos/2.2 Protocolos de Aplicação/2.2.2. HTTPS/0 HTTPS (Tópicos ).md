# 📚 Guia de Estudos: HTTPS — HTTP Seguro
#tag #redes #infraestrutura #internet #https #tls #segurança

> [!info] Visão Geral
> HTTPS é o HTTP com uma camada de segurança TLS (Transport Layer Security) abaixo. Não é um protocolo novo — é o mesmo HTTP com criptografia, autenticação e integridade garantidos pelo TLS. Este sub-glossário cobre como o HTTPS funciona sobre o TCP/HTTP, o que o TLS adiciona, como os certificados funcionam na prática e as boas práticas de configuração (HSTS, mixed content, certificate pinning).
