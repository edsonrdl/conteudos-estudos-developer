### Outros Protocolos Fundamentais da Internet

Além do HTTP, a Internet sustenta outros serviços essenciais — transferência de arquivos e e-mail — com protocolos específicos, cada um com responsabilidades distintas.

---

## FTP — File Transfer Protocol

O FTP (porta 21) foi criado em 1971, antes do próprio TCP/IP moderno. Transfere arquivos entre cliente e servidor usando **duas conexões TCP separadas**:

```
Conexão de controle (porta 21): comandos e respostas
Conexão de dados (porta 20 ou aleatória): o arquivo em si
```

**Modos:**
- **Ativo**: servidor inicia a conexão de dados de volta ao cliente — problemático com firewalls
- **Passivo** (PASV): cliente inicia ambas as conexões — padrão moderno

**Status atual:** FTP transmite credenciais em texto puro. Alternativas seguras:
- **SFTP** (SSH File Transfer Protocol) — FTP sobre SSH, porta 22
- **FTPS** (FTP Secure) — FTP sobre TLS, porta 990
- **SCP** — transferência simples via SSH

---

## SMTP — Simple Mail Transfer Protocol

O SMTP (porta 25, ou 587 com autenticação) é o protocolo para **envio** de e-mail — tanto do cliente ao servidor quanto entre servidores de e-mail.

```
Fluxo de um e-mail:
  Remetente                                    Destinatário
  [Gmail]──SMTP──>[Servidor Google]──SMTP──>[Servidor Destino]──IMAP/POP3──>[Outlook]
```

**Portas:**
| Porta | Uso |
|-------|-----|
| 25 | SMTP entre servidores (MTA to MTA) |
| 587 | SMTP autenticado (cliente → servidor, com STARTTLS) |
| 465 | SMTPS (SMTP sobre TLS implícito) |

---

## IMAP vs POP3 — Recebimento de E-mail

IMAP e POP3 são protocolos para que **clientes de e-mail leiam mensagens** do servidor. São distintos do SMTP (que envia).

| Característica | IMAP (porta 993) | POP3 (porta 995) |
|----------------|------------------|------------------|
| Mensagens ficam onde | No servidor | Baixadas para o cliente |
| Acesso multi-dispositivo | Sim — todos veem a mesma caixa | Não — só o dispositivo que baixou |
| Sincronização de pastas | Sim | Não |
| Uso offline | Limitado | Total (após download) |
| Uso moderno | Padrão | Obsoleto na prática |

**IMAP** é o padrão atual — permite que o mesmo e-mail apareça sincronizado no celular, notebook e webmail.

## 🧩 Quiz de Fixação

1. Qual a diferença entre SMTP e IMAP?
2. Por que FTP puro não deve ser usado em produção?
3. Por que IMAP substituiu POP3 como padrão moderno?

**Respostas:**
1) SMTP envia e-mails (do cliente ao servidor e entre servidores). IMAP é usado pelo cliente para *ler* e-mails que estão no servidor.
2) FTP transmite usuário, senha e dados em texto puro — qualquer um que intercepte o tráfego vê as credenciais. Use SFTP (sobre SSH) ou FTPS (sobre TLS) em seu lugar.
3) IMAP mantém as mensagens no servidor e sincroniza o estado (lido, pasta, etc.) entre múltiplos dispositivos. POP3 baixa e remove do servidor, impossibilitando acesso de outros dispositivos.
