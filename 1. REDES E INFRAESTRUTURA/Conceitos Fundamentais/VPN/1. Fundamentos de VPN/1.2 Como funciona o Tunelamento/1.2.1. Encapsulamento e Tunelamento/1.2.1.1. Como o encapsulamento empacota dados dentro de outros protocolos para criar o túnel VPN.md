### Encapsulamento e tunelamento — como o túnel VPN é construído

O tunelamento é o mecanismo técnico por trás da VPN. Ele funciona embalando (encapsulando) pacotes de dados dentro de outros pacotes, criando um "tubo" virtual dentro da rede pública.

---

## O que é encapsulamento

Encapsulamento é o processo de pegar um pacote completo (header + payload) e colocá-lo como payload de um novo pacote externo.

```
Pacote original (privado):
┌──────────────┬──────────────────────────────┐
│ Header (IP)  │ Dados (ex: requisição HTTP)  │
└──────────────┴──────────────────────────────┘

Após encapsulamento VPN:
┌──────────────┬──────────────────────────────────────────────────────┐
│ Header VPN   │ [Header IP original | Dados cifrados]                │
│ (IP público) │           ↑ pacote inteiro virou payload             │
└──────────────┴──────────────────────────────────────────────────────┘
```

O roteador na internet só vê o header externo (IP do cliente → IP do servidor VPN). O conteúdo interno é opaco e criptografado.

---

## As camadas do tunelamento

```
Camada de Aplicação:  HTTP request para intranet.empresa.com
         ↓
Camada VPN:           Cifra + encapsula em protocolo VPN (ex: IPsec)
         ↓
Camada de Transporte: UDP ou TCP para o servidor VPN
         ↓
Camada de Rede:       IP público (seu IP real → IP do servidor VPN)
         ↓
Rede física/pública:  Tráfego aparentemente normal para observadores externos
```

---

## Tunelamento vs Criptografia

São conceitos distintos mas usados juntos na VPN:

| Conceito | Função | Obrigatório para VPN? |
|---|---|---|
| **Tunelamento** | Encapsula o pacote original dentro de outro | Sim |
| **Criptografia** | Cifra o conteúdo do pacote interno | Na prática sim (sem ela, VPN não tem valor) |

Existem VPNs sem criptografia (usadas para conectar redes logicamente), mas qualquer VPN moderna cifra os dados.

---

## Exemplo prático: WireGuard

O WireGuard encapsula o tráfego em pacotes UDP:

```
[Pacote IP original] → cifrado com ChaCha20 → empacotado em UDP → enviado ao peer VPN
```

Do ponto de vista da internet, parece simplesmente tráfego UDP entre dois IPs.

## 🧩 Quiz de Fixação

1. O que é encapsulamento no contexto de VPN?
2. Por que um observador na internet não consegue ver o conteúdo do tráfego tunelado?
3. É possível fazer tunelamento sem criptografia? Dê um exemplo de quando isso faria sentido.

**Respostas:**
1) É o processo de empacotar um pacote completo (header + dados) como payload de um novo pacote externo, escondendo o conteúdo original.
2) O pacote interno é criptografado antes de ser encapsulado — o observador vê apenas o header externo (IPs de origem e destino da VPN).
3) Sim — em redes privadas onde já há segurança física (ex.: GRE tunnels entre roteadores internos de uma empresa para conectar VLANs sem necessidade de cifrar).
