### A matemática do Subnetting

O processo de criar sub-redes envolve **pegar bits emprestados** da porção de host e convertê-los em bits de rede. Cada bit emprestado dobra o número de sub-redes e reduz pela metade os hosts por sub-rede.

**Fórmulas fundamentais:**

```
Número de sub-redes   = 2^(bits emprestados)
Hosts úteis/sub-rede  = 2^(bits de host restantes) - 2
Salto entre sub-redes = 2^(bits de host restantes)
Nova máscara (CIDR)   = máscara original + bits emprestados
```

---

## Exemplo base — Dividir `192.168.1.0/24` em 2 sub-redes

**A Rede Original (/24):**
- Intervalo: `192.168.1.0` a `192.168.1.255`
- Total: 256 IPs — 254 utilizáveis
- Objetivo: separar PCs (Dep. A) das Impressoras (Dep. B)

**O Cálculo:**
Para dividir por 2, emprestamos 1 bit (de `/24` para `/25`):

- Bits emprestados: 1
- Sub-redes criadas: $2^1 = 2$
- Bits de host restantes: $32 - 25 = 7$
- Hosts úteis por sub-rede: $2^7 - 2 = 126$
- Salto: $2^7 = 128$
- Máscara: `255.255.255.128`

**Resultado:**

| Sub-rede | Endereço de Rede | Hosts válidos | Broadcast | Máscara |
| -------- | ---------------- | ------------- | --------- | ------- |
| A (PCs) | `192.168.1.0` | `.1` a `.126` | `.127` | `/25` |
| B (Impressoras) | `192.168.1.128` | `.129` a `.254` | `.255` | `/25` |

## Tabela de bits emprestados — referência rápida

Partindo de uma rede `/24`:

| Bits emprestados | Nova máscara | Sub-redes | Hosts úteis/sub-rede | Salto |
| ---------------- | ------------ | --------- | -------------------- | ----- |
| 1 | /25 | 2 | 126 | 128 |
| 2 | /26 | 4 | 62 | 64 |
| 3 | /27 | 8 | 30 | 32 |
| 4 | /28 | 16 | 14 | 16 |
| 5 | /29 | 32 | 6 | 8 |
| 6 | /30 | 64 | 2 | 4 |

## Como determinar o endereço de cada sub-rede

Com o salto calculado, lista-se os múltiplos do salto no octeto afetado:

**Exemplo com `/26` (salto = 64) em `192.168.1.0`:**

```
Sub-rede 1: 192.168.1.0    → hosts .1 a .62   → broadcast .63
Sub-rede 2: 192.168.1.64   → hosts .65 a .126  → broadcast .127
Sub-rede 3: 192.168.1.128  → hosts .129 a .190 → broadcast .191
Sub-rede 4: 192.168.1.192  → hosts .193 a .254 → broadcast .255
```

**Regra rápida para o salto:**
```
Salto = 256 - valor decimal da máscara no octeto "quebrado"
Exemplo: máscara /26 → 4º octeto = 192 → salto = 256 - 192 = 64
```

## 🧩 Quiz de Fixação

1. Quantas sub-redes são criadas ao emprestar 3 bits de uma rede `/24`?
2. Qual é o salto entre sub-redes com máscara `/27`?
3. Uma empresa precisa de 10 sub-redes com ao menos 20 hosts cada. Qual máscara usar em um bloco `/24`?

**Respostas:** 1) $2^3 = 8$ sub-redes, 2) Salto = $256 - 224 = 32$, 3) `/27` — cria 8 sub-redes com 30 hosts cada; para 10 sub-redes precisaria de `/28` (16 sub-redes, 14 hosts) — escolha depende da prioridade entre número de redes ou hosts.
