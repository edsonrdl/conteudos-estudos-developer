### O que são os Intervalos e como identificar cada Classe

| **Termo**       | **O que é**                                                                                                                     | **Exemplo Visual** |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------- | ------------------ |
| **Endereço IP** | É a identidade numérica única de um dispositivo em uma rede. No IPv4, é composto por 32 bits (4 octetos), separados por pontos. | **192.168.1.10**   |

---

## 🅰️ Classe A — Redes Enormes

A Classe A é usada para redes muito grandes, onde o primeiro octeto define a rede e os três restantes definem os hosts.

| **Parâmetro**                | **Valor**              |
| ---------------------------- | ---------------------- |
| **Faixa do 1º Octeto**       | **1 a 126**            |
| **IP de Exemplo**            | `10.200.50.3`          |
| **Máscara Padrão (CIDR)**    | `/8`                   |
| **Máscara Padrão (Decimal)** | `255.0.0.0`            |

**Divisão Rede/Host:**
- **Rede:** 1º Octeto (`10`).
- **Host:** 2º, 3º e 4º Octetos (`200.50.3`).

**Cálculo (Operação AND):**

| Parte      | Valor               |
| ---------- | ------------------- |
| IP         | `10` . 200 . 50 . 3 |
| Máscara    | `255` . 0 . 0 . 0   |
| Endereço da Rede | `10` . 0 . 0 . 0 |

**Endereços (Intervalo):**
- **Endereço da Rede:** `10.0.0.0`
- **Primeiro Host Válido:** `10.0.0.1`
- **Último Host Válido:** `10.255.255.254`
- **Broadcast:** `10.255.255.255`
- **Total de Hosts Úteis:** $2^{24} - 2 \approx 16,7$ Milhões (24 bits de host)

---

## 🅱️ Classe B — Redes Médias a Grandes

A Classe B é usada para redes de tamanho médio a grande, onde os dois primeiros octetos definem a rede.

| **Parâmetro**                | **Valor**              |
| ---------------------------- | ---------------------- |
| **Faixa do 1º Octeto**       | **128 a 191**          |
| **IP de Exemplo**            | `172.16.20.100`        |
| **Máscara Padrão (CIDR)**    | `/16`                  |
| **Máscara Padrão (Decimal)** | `255.255.0.0`          |

**Divisão Rede/Host:**
- **Rede:** 1º e 2º Octetos (`172.16`).
- **Host:** 3º e 4º Octetos (`20.100`).

**Endereços (Intervalo):**
- **Endereço da Rede:** `172.16.0.0`
- **Primeiro Host Válido:** `172.16.0.1`
- **Último Host Válido:** `172.16.255.254`
- **Broadcast:** `172.16.255.255`
- **Total de Hosts Úteis:** $2^{16} - 2 = 65.534$ Hosts

---

## 🇨 Classe C — Redes Pequenas

A Classe C é a mais comum para redes locais pequenas.

| **Parâmetro**                | **Valor**              |
| ---------------------------- | ---------------------- |
| **Faixa do 1º Octeto**       | **192 a 223**          |
| **IP de Exemplo**            | `192.168.1.5`          |
| **Máscara Padrão (CIDR)**    | `/24`                  |
| **Máscara Padrão (Decimal)** | `255.255.255.0`        |

**Divisão Rede/Host:**
- **Rede:** 1º, 2º e 3º Octetos (`192.168.1`).
- **Host:** 4º Octeto (`5`).

**Endereços (Intervalo):**
- **Endereço da Rede:** `192.168.1.0`
- **Primeiro Host Válido:** `192.168.1.1`
- **Último Host Válido:** `192.168.1.254`
- **Broadcast:** `192.168.1.255`
- **Total de Hosts Úteis:** $2^{8} - 2 = 254$ Hosts
