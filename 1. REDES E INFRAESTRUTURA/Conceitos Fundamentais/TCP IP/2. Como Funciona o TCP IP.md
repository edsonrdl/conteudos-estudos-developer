O modelo TCP/IP é o padrão de comunicação da internet. Diferente de uma aplicação única, ele é um **conjunto de protocolos** organizados em camadas para garantir que os dados saiam de um ponto A e cheguem ao ponto B com integridade.

### 🔹 2.1 Explicação da Pilha (As 4 Camadas)

A "pilha" TCP/IP organiza as funções de rede em 4 níveis hierárquicos. Cada camada resolve um problema específico e passa o resultado para a próxima.

1. **Aplicação:** Onde estão os protocolos que os programas usam (HTTP para web, SMTP para e-mail, FTP para arquivos).
    
2. **Transporte:** Responsável pela comunicação fim-a-fim. Define se a entrega será garantida (**TCP**) ou rápida/direta (**UDP**).
    
3. **Internet:** Cuida do endereçamento e da melhor rota. É aqui que o **IP** (IPv4 ou IPv6) atua.
    
4. **Rede (ou Acesso):** Define como os bits serão transmitidos fisicamente pelos cabos, Wi-Fi ou fibra ótica (Ethernet).

### 🔹 2.2 OSI vs TCP/IP

Embora o TCP/IP seja o modelo prático usado na Internet, o **Modelo OSI** é o padrão teórico de 7 camadas usado para ensino e diagnóstico de problemas.

|**Camada OSI**|**Camada TCP/IP**|**Função Principal**|
|---|---|---|
|7. Aplicação / 6. Apresentação / 5. Sessão|**Aplicação**|Interface com o usuário e formatação de dados.|
|4. Transporte|**Transporte**|Controle de fluxo e correção de erros.|
|3. Rede|**Internet**|Endereçamento lógico e roteamento.|
|2. Enlace / 1. Física|**Rede (Acesso)**|Transformação de dados em sinais físicos (bits).|

> **Nota:** O modelo TCP/IP é mais "enxuto", fundindo as camadas superiores e inferiores do OSI para simplificar a implementação.

### 🔹 2.3 O Processo de Encapsulamento

O encapsulamento é o processo de "embrulhar" os dados conforme eles descem as camadas. Imagine uma carta (Dados) sendo colocada dentro de vários envelopes sucessivos até chegar ao caminhão de entrega.

1. **Dados:** A camada de Aplicação gera a mensagem.
    
2. **Segmento:** A camada de Transporte adiciona o cabeçalho TCP (número da porta).
    
3. **Pacote:** A camada de Internet adiciona o cabeçalho IP (endereços de origem e destino).
    
4. **Quadro (Frame):** A camada de Rede adiciona o endereço MAC e o controle de erros físico.
    

Ao chegar no destino, ocorre o **Desencapsulamento**: cada camada retira seu respectivo "envelope" e lê a instrução, até que sobrem apenas os dados originais para o aplicativo.

---

### 🔹 Resumo Prático: Diferença entre TCP e IP

Para não confundir as funções dentro da pilha:

- **IP (O Carteiro):** Identifica e direciona os pacotes para o destino correto usando os endereços. Ele não se importa se o pacote caiu no chão, ele apenas tenta entregar.
    
- **TCP (O Conferente):** Garante que a mensagem chegue completa. Se um pacote sumir, ele pede o reenvio. Se chegarem fora de ordem, ele os organiza.
