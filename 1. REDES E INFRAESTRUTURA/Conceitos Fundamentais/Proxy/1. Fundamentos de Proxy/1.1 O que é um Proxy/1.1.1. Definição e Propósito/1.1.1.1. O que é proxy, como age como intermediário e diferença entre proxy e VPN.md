### O que é proxy e como age como intermediário

Um proxy é um servidor que atua como intermediário entre um cliente e um destino. Em vez de o cliente se comunicar diretamente com o servidor de destino, a requisição passa pelo proxy — que a encaminha, podendo inspecionar, modificar, cachear ou bloquear o tráfego.

---

## A essência do proxy

```
Sem proxy:
  [Cliente] ──────────────────────────► [Servidor]

Com proxy:
  [Cliente] ──► [PROXY] ──► [Servidor]
                  ↑
         Intermediário que pode:
         - Inspecionar a requisição
         - Modificar headers
         - Cachear a resposta
         - Bloquear o acesso
         - Ocultar o IP do cliente
```

O servidor de destino vê o IP do proxy, não o do cliente original.

---

## O que o proxy pode fazer

| Função | Descrição |
|---|---|
| **Encaminhamento** | Repassa requisições ao destino |
| **Cache** | Armazena respostas para reutilização — reduz latência e banda |
| **Filtragem** | Bloqueia URLs, categorias de conteúdo, malware |
| **Anonimização** | Oculta o IP real do cliente do servidor destino |
| **Balanceamento** | Distribui requisições entre múltiplos servidores (reverse proxy) |
| **Inspeção SSL** | Decifra, inspeciona e re-cifra tráfego HTTPS |
| **Autenticação** | Exige login antes de permitir acesso à internet |

---

## Proxy vs VPN — qual a diferença?

| Aspecto | Proxy | VPN |
|---|---|---|
| **Escopo** | Geralmente por aplicação/protocolo | Todo o tráfego do dispositivo |
| **Criptografia** | Não necessariamente (depende do tipo) | Sempre criptografa o túnel |
| **Configuração** | Por app (browser, sistema) | Nível de SO/interface de rede |
| **Velocidade** | Geralmente mais rápido | Overhead do tunelamento |
| **Uso típico** | Cache, filtragem, balanceamento | Acesso remoto, privacidade total |
| **Anonimato** | Parcial (proxy vê tudo) | Maior (ISP só vê IP do servidor VPN) |

O proxy opera tipicamente na **camada de aplicação** — ele entende HTTP, HTTPS, FTP. A VPN opera na **camada de rede** — tunela todos os protocolos.

---

## Por que proxies são fundamentais na infraestrutura moderna

- **Corporativo:** controle e auditoria do acesso à internet dos funcionários.
- **CDN:** proxy de cache distribuído geograficamente para servir conteúdo estático.
- **API Gateway:** reverse proxy que centraliza autenticação, rate limiting e roteamento.
- **Microserviços:** service mesh usa proxies sidecar (Envoy) para comunicação entre serviços.

## 🧩 Quiz de Fixação

1. Qual a principal diferença de escopo entre um proxy e uma VPN?
2. Quando um servidor web recebe uma requisição via forward proxy, qual IP ele enxerga?
3. Por que uma empresa pode preferir proxy a VPN para controlar o acesso à internet dos funcionários?

**Respostas:**
1) O proxy atua tipicamente por aplicação/protocolo; a VPN cobre todo o tráfego do dispositivo na camada de rede.
2) O IP do servidor proxy — não o IP real do cliente (a menos que o proxy adicione o header X-Forwarded-For).
3) O proxy permite inspeção, filtragem de conteúdo, cache e autenticação por usuário — funcionalidades que a VPN não oferece nativamente.
