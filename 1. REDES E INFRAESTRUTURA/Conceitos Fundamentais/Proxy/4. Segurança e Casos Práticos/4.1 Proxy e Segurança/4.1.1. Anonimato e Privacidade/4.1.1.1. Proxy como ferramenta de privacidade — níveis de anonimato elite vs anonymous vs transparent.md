### Proxy como ferramenta de privacidade — níveis de anonimato

Nem todo proxy oferece o mesmo nível de privacidade. A classificação em transparente, anônimo e elite define o quanto o servidor destino consegue saber sobre o cliente real.

---

## Os três níveis de anonimato

### Nível 1 — Proxy Transparente

O proxy encaminha a requisição revelando tanto o IP do proxy quanto o IP real do cliente:

```
Headers enviados ao servidor destino:
  X-Forwarded-For: 203.0.113.10   ← IP real do cliente (exposto!)
  Via: 1.1 proxy.empresa.com      ← indica que passou por proxy

Resultado: servidor sabe que você usa proxy E sabe seu IP real.
Utilidade para privacidade: nenhuma.
```

### Nível 2 — Proxy Anônimo (Anonymous)

O proxy oculta o IP real mas indica que é um proxy:

```
Headers enviados ao servidor destino:
  X-Forwarded-For: 198.51.100.1   ← IP do proxy (não o real)
  Via: 1.1 proxy.provider.com     ← ainda indica que é proxy

Resultado: servidor não sabe seu IP real, mas sabe que você usa proxy.
Utilidade: oculta o IP real — suficiente para a maioria dos casos.
```

### Nível 3 — Proxy Elite (High Anonymity)

O proxy parece uma conexão direta normal:

```
Headers enviados ao servidor destino:
  [sem X-Forwarded-For]
  [sem Via]
  [sem Proxy-Connection]

Resultado: servidor recebe a requisição como se viesse diretamente do IP do proxy.
Não há indicação de que é um proxy.
Utilidade: máximo anonimato entre os proxies HTTP.
```

---

## Comparativo

| Nível | Oculta IP real? | Revela uso de proxy? | Uso típico |
|---|---|---|---|
| Transparente | Não | Sim | Cache corporativo — sem objetivo de privacidade |
| Anônimo | Sim | Sim | Privacidade básica |
| Elite | Sim | Não | Máximo anonimato HTTP |

---

## O que o proxy não esconde

Mesmo um proxy elite tem limitações:

| Identificador | Proxy esconde? |
|---|---|
| IP do cliente | Sim |
| Cookies | Não — browser os envia normalmente |
| Fingerprinting do browser | Não — JS/canvas/WebGL revelam identidade |
| Login em contas | Não — você se identifica ao logar |
| DNS leaks | Depende da configuração |
| Tráfego fora do browser | Não — apenas apps configurados para usar o proxy |

## Proxy vs Tor para anonimato

```
Proxy Elite:
  Você ──► Proxy ──► Destino
  1 salto — o operador do proxy vê tudo

Tor (The Onion Router):
  Você ──► Nó 1 ──► Nó 2 ──► Nó 3 (exit) ──► Destino
  3 saltos — nenhum nó vê origem E destino simultaneamente
```

Para anonimato real, Tor oferece garantias muito maiores — mas com latência significativamente maior.

## 🧩 Quiz de Fixação

1. Qual a diferença prática entre um proxy anônimo e um proxy elite?
2. Por que usar um proxy elite não garante anonimato completo?
3. Por que o Tor oferece mais anonimato que um proxy elite?

**Respostas:**
1) O anônimo oculta o IP real mas envia headers (Via, X-Forwarded-For) que revelam o uso de proxy; o elite remove todos esses headers — a requisição parece vir diretamente do IP do proxy.
2) Porque o operador do proxy vê todo o tráfego, cookies e fingerprinting do browser ainda identificam o usuário, e qualquer login em conta desfaz o anonimato imediatamente.
3) No Tor, o tráfego passa por 3 nós: o primeiro sabe quem você é mas não o destino; o último (exit node) sabe o destino mas não quem você é. Nenhum nó tem a visão completa — diferente do proxy onde o operador vê tudo.
